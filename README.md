# boom-boom-unfriender
Chrome side-panel extension to review and bulk-remove Facebook friends — fast filtering, speed-tiered removal, and license-gated unlimited mode.
Boom Boom Unfriender is a Manifest V3 Chrome extension that opens a side panel next to Facebook, lets you filter your friends list (mutual/non-mutual, no-photo, name), and bulk-remove them at a chosen speed. Built with React + Vite, backed by a daily-quota free tier and a licensed unlimited tier.
